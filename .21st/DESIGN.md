# RailShield design context

React/TypeScript operational planning workstation. The selected direction uses a light canvas, ink navy navigation, teal planning actions, and separate ENG/SNT/TRD colors. CSS tokens live in `frontend/src/styles.css`; the Cytoscape view reads those tokens. DM Sans and Manrope fonts are bundled locally.

Use compact, readable panels and tables. Preserve keyboard labels, focus outlines, reduced motion, mobile navigation and explicit loading/error/empty states. Pair color with text. Every metric must originate in a persisted result and carry the correct plan lineage.

The 21st catalog was searched for operational dashboard patterns. No component source was copied. See `docs/decisions/0001-model-and-ui.md` for the timeline and framework decisions.
