# Six-minute demonstration

1. **Inputs (45s):** Open Data sources. Show the reproducible seed, explicit synthetic label and JSON import. Explain how three departmental demand sources map into one validated contract.
2. **Hierarchy (45s):** Build monthly commitments. Explain that weekly budgets are advisory, then Generate plan to establish exact feasibility across the horizon.
3. **Coordination (90s):** Show the independent baseline, measured possession time and completed task count. Open a day with work in the timeline. Inspect ENG/SNT overlap and a TRD interval. The compatibility matrix and global crew capacity govern sharing; the union is charged once.
4. **Explainability (45s):** Show objective contributions and solver status/bound. Required deadlines and train conflicts remain hard when weights change. A FEASIBLE result is not a claim of optimality.
5. **Stress (60s):** Run the seeded 20-scenario experiment. Expand a violation to identify the exact task/resource/window. This checks the original starts, without quietly replanning.
6. **Recovery (60s):** Inject a two-slot task overrun, Recover plan, and compare changed tasks to the full replan. Lock a task first to demonstrate that impossible locks yield infeasibility instead of silent changes.
7. **Traceability (15s):** Open Plan history and export a job. Original input/plan versions remain available.

Do not quote fixed percentages from slides: use the displayed experiment. Start with the six-task browser fixture for the fastest demo, or the 24-task default for a richer schedule. Short CPU budgets may change the incumbent; inspect status and scheduled-task comparability.
